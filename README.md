# FinanceX

本地个人财务管理：导入账单时确认分类，盘点时持仓自动估值，资产负债表、利润表、现金流量表自动生成。
所有数据只在本机（`data/wealthx.db` 一个文件），只监听 `127.0.0.1`。

## 启动

需要 Windows 10/11 + Python 3.10 以上。

- **双击 `start.bat`**：首次会创建 `.venv` 并安装依赖（只有 `pdfplumber`，用于解析信用卡 PDF），然后自动打开浏览器 <http://127.0.0.1:8730/>。关闭命令行窗口即退出。
- **双击 `demo.bat`**：用演示数据体验（`data/demo.db`，端口 8731），不影响正式数据。

也可以手动运行：

```bash
python -m financex --port 8730
```

## 每月流程

1. **导入账单**（顶部「导入账单」）：拖入支付宝 CSV（GBK）、微信 xlsx、农行信用卡 PDF。
   预览里逐条确认类型与分类：交易关闭的已跳过，按订单号拦截重复导入，信用卡与支付宝 / 微信金额相同、日期差 ≤ 1 天的标为疑似重复（默认不导入信用卡一侧），分类按「该商户最近一笔已入账流水」预填。入账前自动备份，账单页可「撤销这次导入」。
2. **复制上月流水**（账单页）：工资、社保、公积金、个税、房租等固定收支，复制到本月同一天（没有那天取月末），金额可改。
3. **盘点**（总览 →「盘点」）：手填账户填余额（可复制上月值，负债填负数），持仓标的自动取价估值，完成后存为当月快照 = 当月资产负债表。
4. 偶发：持仓页录入买入 / 卖出、购汇 / 结汇；卖出人民币标的、结汇会自动生成「投资收益」流水。

## 记账口径（摘要）

- 持仓按移动加权平均成本；外币标的的已实现盈亏按原币记录，不进利润表；港股通按人民币标的记账。
- 购汇：新成本 =（购汇余额 × 旧成本 + 支付人民币）÷（购汇余额 + 获得外币）；结汇：汇兑损益 = 收到人民币 − min(数量, 购汇余额) × 平均成本。
- 结余 = 收入 − 支出；储蓄率 = 结余 ÷ 收入（当月无工资收入时不显示）；消费支出 = 支出 − 工资减扣。
- 投资净投入 = 人民币买入 + 购汇 − 人民币标的卖出部分的成本 − 结汇本金（期初录入不计）。
- 快照存档后不自动重算；事后补录的交易不改写过去的快照。

## 联网

只有两处会联网，请求里只含标的代码与币种：

- 盘点时取价与汇率：东方财富行情（A 股 / ETF / 港股 / 美股）、天天基金净值（场外基金）、OKX（加密货币）、open.er-api.com（汇率）。取不到的格留空待手填。
- 新增标的时手动点「识别」，按代码查名称。

前端不加载任何外部资源，离线可用。

## 备份与迁移

- 每次启动、每次导入前、覆盖已有盘点前自动备份到 `data/backups/`，每类保留最近 10 份，「分类与备份」页可一键恢复。
- 「分类与备份」页可导出全部流水 CSV（UTF-8）。
- 迁移：把 `data/wealthx.db` 拷到新电脑即可。

## 开发

```
financex/
  server.py     HTTP 服务与 JSON API（标准库 http.server）
  db.py         SQLite 表结构与默认分类
  ledger.py     持仓、购汇重放与自动流水
  reports.py    总览、盘点、持仓与三张报表
  parsers.py    支付宝 / 微信 / 农行信用卡解析
  importer.py   导入预览：拦截、疑似重复、预填
  quotes.py     行情与汇率
  backup.py     自动备份与恢复
  demo.py       演示数据
  static/       前端（原生 JS，无构建步骤）
tests/          单元测试（含 PRD 中的汇兑算例与月度算例）
```

```bash
python -m unittest discover tests
```
